# Autodrome v0.1.0

First fixed release of the self-hosted FastAPI + Vue application.

- Search YouTube playlists and MusicBrainz releases, with provider-specific errors
  and progressive release tracklists.
- Validate only the selected playlist's manifest and reuse recent valid results.
- Download with MusicBrainz metadata or explicitly confirmed manual Artist + Album.
- Preserve numeric audio identity, multidisc order, track artist credits and albumartist.
- Show queue phases and per-track progress; retain failures and support retries.
- Pause and recover queue processing when state writes fail, without repeating
  an already completed download.
- Validate albums in staging and publish atomically without overwriting existing albums.
- Run the compiled frontend, API and WebSocket from FastAPI; install the documented
  non-root systemd service for persistent hosting. Tokens are entered at runtime,
  never embedded in the frontend build.

See the README for installation, configuration, startup and upgrades, and
`docs/v0.1.0-acceptance.md` for real-provider and filesystem acceptance evidence.

Known limits: one backend process and sequential tracks; external provider outages
can fail jobs; interrupted work needs review before retrying; manual mode has no
per-track editor, MusicBrainz date, credits, multidisc metadata or artwork. Queue
cancellation, concurrent tracks, advanced fault injection, reboot and chaos testing
are deferred. Existing npm audit advisories remain a dependency-maintenance follow-up.
